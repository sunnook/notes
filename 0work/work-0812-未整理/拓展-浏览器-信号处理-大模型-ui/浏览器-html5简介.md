## 1. HTML5 不止是“网页协议”，它是一整套技术栈

你记忆中的 HTML 是描述网页结构的**标记语言**（`<div>`、`<p>`、`<a>` 这些）。  
但 **HTML5 是广义的技术合集**，除了新增语义标签，还把很多原本需要插件才能做的事标准化了。

### HTML5 包含的核心技术方向：

| 类别           | 具体技术                                                  | 能干什么                   |
| ------------ | ----------------------------------------------------- | ---------------------- |
| **语义 & 结构**  | `<article>` `<section>` `<nav>` `<header>` `<footer>` | 让搜索引擎和屏幕阅读器更好理解页面      |
| **多媒体**      | `<video>` `<audio>` `<picture>`                       | 不用 Flash 就能直接播放音视频     |
| **图形/游戏**    | `<canvas>`、WebGL、WebGPU、SVG                           | 2D/3D 绘图、网页游戏、数据可视化    |
| **本地存储**     | localStorage、IndexedDB、Cache API                      | 离线存储数据、缓存整个应用          |
| **实时通信**     | WebSocket、WebRTC                                      | 即时聊天、视频通话、直播           |
| **性能 & 线程**  | Web Worker、WebAssembly (Wasm)                         | 在后台跑复杂计算，不卡主页面         |
| **设备访问**     | Geolocation、摄像头/麦克风、陀螺仪、蓝牙                            | 地图定位、扫码、体感控制           |
| **离线 & PWA** | Service Worker、Web App Manifest                       | 网页像原生 App 一样可离线使用、可安装  |
| **样式 & 动画**  | CSS3（Flexbox、Grid、滚动驱动动画、视图切换）                        | 复杂布局、流畅动画，不需要 JS 也能做交互 |

**一句话总结：现代 HTML5 已经不是“写页面”，而是“用浏览器当操作系统，网页就是 App”。**

## 2. 苹果为什么在 HTML5 上能开 50k？

你看到的“苹果 HTML5 50k”招聘，指的其实是 **Web 前端开发工程师**，要求掌握上面这一整套 HTML5 技术栈，而不是只会写 HTML 标签。

### 苹果为什么愿意出这个价？

1. **Safari 是苹果生态的核心入口**  
   苹果需要顶尖工程师去优化 Safari 的渲染引擎（WebKit），让它在 iOS/macOS 上跑 Web 应用更快、更省电。

2. **WebKit 引擎本身极其复杂**  
   浏览器引擎的复杂度不亚于操作系统内核。需要处理：
   
   - HTML/CSS 解析与渲染
   - JavaScript 引擎优化（JIT 编译）
   - WebGPU / WebAssembly 的高性能实现
   - 跨浏览器兼容性（Interop 2026 等标准推进）

3. **苹果在推“网页即 App”**  
   PWA、Service Worker、Web Push 等让网页具备原生 App 的能力。苹果需要这些技术在自己平台上跑得最好，才能跟 Android 的 Web 生态竞争。

4. **人才稀缺**  
   能深入浏览器引擎、Web 标准制定、高性能前端架构的人，全球范围内都很少，50k 是在抢这类顶尖人才。

---

**所以，你印象中的 HTML 是“写网页”，而苹果要的 HTML5 工程师是“造浏览器里的操作系统”。** 这就是 50k 背后的原因。
