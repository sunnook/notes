要在 Linux 中将 `objdump` 的输出结果保存到文件中，可以使用 **输入输出重定向** 功能。以下是具体命令格式和示例：

---

### **基本命令格式**
```bash
objdump [选项] 目标文件 > 输出文件名
```
- `>`：将命令的输出重定向到指定文件，如果文件已存在则覆盖。
- `>>`：追加输出到文件末尾（不覆盖原有内容）。

---

### **常用 objdump 选项**
根据需求选择不同的选项（示例）：
1. **查看符号表（Symbols）**：
   ```bash
   objdump -t 目标文件 > symbols.txt
   ```
   - `-t`：显示目标文件的符号表（包括函数、变量等）。

2. **反汇编代码（Disassembly）**：
   ```bash
   objdump -d 目标文件 > disassembly.txt
   ```
   - `-d`：反汇编代码段。

3. **反汇编所有段（包括数据段）**：
   ```bash
   objdump -D 目标文件 > full_disassembly.txt
   ```

4. **查看节头表（Sections）**：
   ```bash
   objdump -h 目标文件 > sections.txt
   ```

5. **解码 C++ 符号名（如果需要）**：
   ```bash
   objdump -C -t 目标文件 > symbols_c.txt
   ```
   - `-C`：解码 C++ 的名称修饰（Name Mangling）。

---

### **示例命令**
#### **1. 将符号表保存到文件**
```bash
objdump -t libAIP_B4.a > symbols.txt
```
- **输出内容**：符号表信息（如之前的 `HIK_AIP_Proc` 符号）。
- **查看文件**：`cat symbols.txt` 或 `less symbols.txt`。

#### **2. 保存反汇编代码**
```bash
objdump -d libAIP_B4.a > disassembly.txt
```
- **输出内容**：目标文件的反汇编代码（逐条指令）。

#### **3. 追加输出到现有文件**
```bash
objdump -h libAIP_B4.a >> analysis.txt
```
- **作用**：将节头表信息追加到 `analysis.txt`（如果文件不存在则自动创建）。

---

### **验证输出文件**
保存后可以通过以下命令查看文件内容：
```bash
# 查看文件前几行
head 输出文件名

# 分页查看完整内容
less 输出文件名

# 使用文本编辑器（如 nano、vim）
nano 输出文件名
```

### **注意事项**
1. **文件路径**：如果文件名包含空格或特殊字符，需要用引号包裹（如 `> "my output.txt"`）。
2. **权限问题**：确保当前用户有写入目标目录的权限。
3. **覆盖警告**：使用 `>` 会直接覆盖原有文件，操作前请谨慎确认。

---

### **总结**
通过 `objdump` 结合重定向符 `>` 或 `>>`，可以方便地将分析结果保存到文件中。根据目标选择合适的选项（如 `-t`、`-d`、`-h` 等），即可生成你需要的详细分析报告。
