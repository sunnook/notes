### Mutex互斥锁实现

互斥锁（Mutex，Mutual Exclusion）是一种同步机制，用于保护共享资源不被多个线程同时访问。互斥锁确保在任何时刻只有一个线程可以访问共享资源，从而避免数据竞争和不一致的问题。

### 基本概念

- **互斥锁**：一个锁对象，用于保护共享资源。
- **加锁**：线程在访问共享资源之前，必须先获取互斥锁。
- **解锁**：线程在访问完共享资源之后，必须释放互斥锁，以便其他线程可以获取锁。

### 实现方式

互斥锁的实现方式因编程语言和库的不同而有所差异。以下是一些常见的实现方式：

#### 1. POSIX 线程（pthread）中的互斥锁

在 POSIX 线程（pthread）中，可以使用 `pthread_mutex_t` 类型和相关的函数来实现互斥锁。

##### 示例代码

```c
#include <pthread.h>
#include <stdio.h>

// 定义互斥锁
pthread_mutex_t mutex;

// 共享资源
int shared_resource = 0;

// 线程函数
void* thread_function(void* arg) {
    // 加锁
    pthread_mutex_lock(&mutex);

    // 访问共享资源
    shared_resource++;
    printf("Thread %ld: shared_resource = %d\n", (long)arg, shared_resource);

    // 解锁
    pthread_mutex_unlock(&mutex);

    return NULL;
}

int main() {
    // 初始化互斥锁
    pthread_mutex_init(&mutex, NULL);

    // 创建线程
    pthread_t threads[5];
    for (long i = 0; i < 5; i++) {
        pthread_create(&threads[i], NULL, thread_function, (void*)i);
    }

    // 等待线程结束
    for (int i = 0; i < 5; i++) {
        pthread_join(threads[i], NULL);
    }

    // 销毁互斥锁
    pthread_mutex_destroy(&mutex);

    return 0;
}
```

#### 2. C++11 中的互斥锁

在 C++11 及更高版本中，可以使用 `std::mutex` 类来实现互斥锁。

##### 示例代码

```cpp
#include <iostream>
#include <thread>
#include <mutex>

// 定义互斥锁
std::mutex mutex;

// 共享资源
int shared_resource = 0;

// 线程函数
void thread_function(int thread_id) {
    // 加锁
    std::lock_guard<std::mutex> lock(mutex);

    // 访问共享资源
    shared_resource++;
    std::cout << "Thread " << thread_id << ": shared_resource = " << shared_resource << std::endl;
}

int main() {
    // 创建线程
    std::thread threads[5];
    for (int i = 0; i < 5; i++) {
        threads[i] = std::thread(thread_function, i);
    }

    // 等待线程结束
    for (int i = 0; i < 5; i++) {
        threads[i].join();
    }

    return 0;
}
```

### 注意事项

1. **死锁**：确保互斥锁的使用不会导致死锁。例如，避免在一个线程中多次加锁同一个互斥锁。
2. **性能**：频繁的加锁和解锁操作可能会影响性能。尽量减少锁的使用范围，只在必要时加锁。
3. **异常安全**：在 C++ 中，使用 `std::lock_guard` 或 `std::unique_lock` 可以确保在异常情况下也能正确解锁。
