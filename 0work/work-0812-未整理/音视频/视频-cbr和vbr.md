</think>## CBR 和 VBR 是什么？

### 基本概念

```
CBR = Constant Bit Rate（固定码率）
VBR = Variable Bit Rate（可变码率）

它们是码率控制策略，决定编码器如何分配每一帧的数据量。
```

### 代码中体现的差异

```c
// 回到你贴的代码，现在就能看懂了：

case MPP_ENC_RC_MODE_CBR:
{
    // CBR：码率波动范围很窄
    bps_max = uBps * 17 / 16;  // 上限 = 目标 × 1.0625
    bps_min = uBps * 15 / 16;  // 下限 = 目标 × 0.9375
    // 范围：目标码率的 93.75% ~ 106.25%
    // 波动只有 ±6.25%，非常稳定
    break;
}

case MPP_ENC_RC_MODE_VBR:
{
    // VBR：码率波动范围很宽
    bps_max = uBps * 17 / 16;  // 上限 = 目标 × 1.0625
    bps_min = uBps * 1 / 16;   // 下限 = 目标 × 0.0625
    // 范围：目标码率的 6.25% ~ 106.25%
    // 波动巨大，简单画面可以几乎不分配码率
    break;
}
```
