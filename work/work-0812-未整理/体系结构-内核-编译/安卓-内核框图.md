## Android 内核 vs 标准 Linux 内核

```
┌──────────────────────────────────────────────────────────────┐
│                     内核对比                                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  标准 Linux 内核          Android 内核                        │
│  ┌─────────────────┐    ┌─────────────────────────────┐     │
│  │ 进程管理         │    │ 进程管理 + Low Memory Killer │     │
│  │ 内存管理         │    │ 内存管理 + ION/Ashmem       │     │
│  │ 文件系统         │    │ 文件系统 + SDCardFS         │     │
│  │ 网络栈           │    │ 网络栈 + 数据流量统计        │     │
│  │ 设备驱动         │    │ 设备驱动 + Binder/Wakelock  │     │
│  │ 中断处理         │    │ 中断处理                     │     │
│  └─────────────────┘    └─────────────────────────────┘     │
│                                                              │
│  标准接口:                 Android 特有:                      │
│  - fork/exec             - Binder (IPC)                     │
│  - mmap/malloc           - ION/DMA-BUF (内存分配)            │
│  - open/read/write       - Ashmem (共享内存)                │
│  - socket                - Wakelock (电源锁)                │
│                          - Low Memory Killer                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## Android 内核关键特性

| 特性 | 作用 | 为什么 Android 需要 |
|------|------|-------------------|
| **Binder** | 进程间通信 (IPC) | 高效、安全的跨进程调用，权限控制 |
| **Ashmem** | 匿名共享内存 | 进程间共享大块内存，可动态回收 |
| **ION/DMA-BUF** | 内存分配器 | 硬件模块（GPU/DSP）共享内存 |
| **Low Memory Killer** | 内存压力管理 | 内存不足时杀进程，无 swap 分区 |
| **Wakelock** | 电源管理 | 防止系统在关键操作时休眠 |
| **RAM Console** | 崩溃日志 | 保存内核崩溃信息到固定内存区 |

## 核心理解

1. **Android 内核 = Linux 内核 + 移动端定制**
   - 不是完全重写，是在 Linux 基础上打补丁
   - 每个 Android 版本对应特定 Linux 内核版本

2. **为什么不用标准 Linux**
   - 移动设备**无 swap**，需要更激进的内存回收 (LMK)
   - 需要**高效的 IPC** (Binder 替代传统的 pipe/socket)
   - 需要**硬件共享内存**机制 (ION/DMA-BUF)
   - 需要**精细的电源管理** (Wakelock)

3. **GKI (Generic Kernel Image) 趋势**
   - Google 从 Android 11 开始推行**通用内核镜像**
   - 将厂商定制部分隔离到**内核模块**
   - 解决碎片化问题，便于安全更新
